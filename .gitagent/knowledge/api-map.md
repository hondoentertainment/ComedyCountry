# ComedyCountry API Route Map

## Core Data
- `/api/comedians/` — Search, list, CRUD
- `/api/venues/` — Search, list, CRUD, reviews
- `/api/events/` — CRUD, RSVP, attendance
- `/api/search/` — Full-text search

## User & Social
- `/api/user/` — Profile, settings, preferences
- `/api/follow/` — Follow/unfollow comedians, venues, users
- `/api/reviews/` — Event and venue reviews
- `/api/activity/` — Activity feed
- `/api/friends/` — Friend connections
- `/api/messages/` — Direct messaging

## Discovery
- `/api/discovery/` — Personalized feed
- `/api/for-you/` — For You page
- `/api/trending/` — Trending entities
- `/api/happening-tonight/` — Tonight's shows by location
- `/api/recommendations/` — Recommendation engine
- `/api/taste-profile/` — Comedy taste profiling

## Ticketing
- `/api/tickets/` — Purchase, transfer, verify
- `/api/checkout/` — Stripe checkout
- `/api/refunds/` — Ticket refunds
- `/api/season-passes/` — Season pass management
- `/api/fair-ticketing/` — Anti-scalping

## Creator
- `/api/creator/` — Creator dashboard
- `/api/creator-intelligence/` — Revenue, audience
- `/api/podcast-pipeline/` — Podcast sync
- `/api/clips/` — Short-form clips
- `/api/exclusive-content/` — Gated content

## Venue Operations
- `/api/venue-ops/` — POS, capacity, staff
- `/api/venue-crm/` — Customer management
- `/api/venue-dashboard/` — Analytics
- `/api/venue-groups/` — Multi-venue

## Community
- `/api/discussions/` — Threads & replies
- `/api/live-chat/` — Event live chat
- `/api/fan-clubs/` — Fan clubs
- `/api/polls/` — Polls & voting

## Admin & Integrations
- `/api/admin/` — Admin operations
- `/api/analytics/` — Metrics
- `/api/stripe/` — Payment webhooks
- `/api/youtube/` — YouTube sync
- `/api/notifications/` — Push notifications
- `/api/cron/` — Scheduled jobs
